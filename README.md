# Tashmoy Ghosh — Research Portfolio

A custom, dependency-light academic portfolio designed for GitHub Pages.

## Design approach
This site combines:
- **Academic Pages:** persistent researcher profile, compact academic navigation, explicit CV/experience structure.
- **al-folio:** modern typography, light/dark mode, prominent recent news, publication-first presentation, project cards, whitespace-heavy visual hierarchy.

The implementation is plain HTML/CSS/JS to avoid Jekyll build conflicts and keep deployment reliable.

## Local preview
Run in this folder:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.
